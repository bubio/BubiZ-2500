# 使い方

## 起動

```
BubiZ-2500 [-option] [image-file [image-No]] [image-file [image-No]] ...
```

書式は QUASI88 に準じています。イメージファイルは拡張子で種類を判定します。フロッピーは先頭から順にドライブ1〜4へ割り当てます。ファイル名の直後の数字は、複数のイメージを含むファイル内の番号(1始まり)です。

```
BubiZ-2500 game.d88            # ドライブ1に挿入して起動
BubiZ-2500 game.d88 2          # 複数イメージを含むファイルの2番目を挿入
BubiZ-2500 disk1.d88 disk2.d88 # ドライブ1と2に挿入
```

## コマンドラインオプション

### 共通

| オプション | 説明 |
|------------|------|
| `-help` | ヘルプを表示して終了 |
| `-version` | バージョンを表示して終了 |
| `-verbose <n>` | 冗長レベル |

### フォルダ・設定

| オプション | 説明 |
|------------|------|
| `-romdir <path>` | BIOS ROM・設定・ステートのフォルダ |
| `-diskdir <path>` | ディスクイメージのフォルダ |
| `-tapedir <path>` | テープイメージのフォルダ |
| `-statedir <path>` | ステートの保存先 |
| `-snapdir <path>` | スクリーンショットの保存先(既定: ピクチャ/BubiZ-2500) |
| `-sounddir <path>` | 録音(WAV)の保存先(既定: ミュージック/BubiZ-2500) |
| `-noconfig` | 設定ファイルを読み込まない |
| `-saveconfig` / `-nosaveconfig` | 終了時に設定ファイルを更新する / しない(既定: する) |

### メディア

| オプション | 説明 |
|------------|------|
| `-hd1 <file>` / `-hd2 <file>` | ハードディスク1・2を接続 |
| `-tapeload <file>` | ロード用テープイメージ |
| `-tapesave <file>` | セーブ用テープイメージ |

### 本体の設定

| オプション | 説明 |
|------------|------|
| `-mz2500` / `-mz2000` / `-mz80b` | 起動モード |
| `-monitor <n>` | モニタータイプ |
| `-optsw <n>` | オプションスイッチ(拡張ボード構成) |
| `-skipline` / `-interlace` | 走査線を描画しない |
| `-nointerlace` / `-scanline` | 走査線を描画する |

### 画面

| オプション | 説明 |
|------------|------|
| `-full` / `-half` / `-double` | 画面サイズ(標準 / 半分 / 2倍) |
| `-aspect <400\|480>` | 縦横比(640x400 / 640x480。既定は 400) |
| `-fullscreen` / `-window` | フルスクリーン / ウィンドウ |
| `-width <x>` / `-height <y>` | ウィンドウサイズ |
| `-filter <none\|rgb>` | 画面フィルタ(rgb: CRT の RGB サブピクセル表示。既定: none) |
| `-interp` / `-nointerp` | 拡大時に補間する / しない(既定: しない) |
| `-show_fps` / `-hide_fps` | ウィンドウタイトルに FPS を表示する / しない |

### 動作・入出力

| オプション | 説明 |
|------------|------|
| `-wait` / `-nowait` | ウェイトあり / なし(全速) |
| `-speed <rate>` | 実時間との比率(%) |
| `-sound` / `-nosound` | サウンドの有無 |
| `-samplefreq <hz>` | サンプリング周波数 |
| `-mouse` / `-nomouse` | マウスのエミュレート |
| `-joystick` / `-nojoystick` | キーボードによるジョイスティックで起動する / しない(既定: しない) |
| `-debug` | 起動時にデバッガーを開く |
| `-resume` | 起動時にステート(スロット0)を復元 |
| `-resumefile <file>` | 起動時に指定したステートを復元 |

### 検証用(ウィンドウなしで実行)

| オプション | 説明 |
|------------|------|
| `-headless <frames>` | ウィンドウを開かず、指定フレーム数を実行して終了 |
| `-screenshot <file>` | `-headless` の終了時の画面を PNG で保存 |
| `-key <frame>:<key>[:<hold>]` | 指定フレームでキーを押す(複数指定可)。`key` は英数字1文字、`RETURN` `SPACE` `ESC` `TAB` `BS` `UP` `DOWN` `LEFT` `RIGHT` `F1`〜`F12` `SHIFT` `CTRL` など。`hold` は押し続けるフレーム数(既定 3) |
| `-wav <file>` | `-headless` 中の音声を WAV で録音(`-nosound` とは併用不可) |
| `-savestate <frame>:<slot>` | 指定フレームでステートを保存(スロット番号は 0 から) |
| `-loadstate <frame>:<slot>` | 指定フレームでステートを復元 |
| `-shotat <frame>:<file>` | 指定フレームの画面を BMP で保存(複数指定可) |

## ホットキー

| キー | 動作 |
|------|------|
| F11 | フルスクリーンの切り替え |
| F12 | リセット(Ctrl+F12: スペシャルリセット) |
| Ctrl+P | 一時停止 / 再開 |
| Ctrl+S | スクリーンショットを保存(PNG) |
| Ctrl+F1〜F4 | ステートを保存(スロット1〜4) |
| Ctrl+Shift+F1〜F4 | ステートを復元(スロット1〜4) |
| Ctrl+F | 画面フィルタ(RGB)の切り替え |
| Ctrl+J | キーボードによるジョイスティックの切り替え(矢印キー=方向、Z=ボタン1、X=ボタン2) |
| Ctrl+D | デバッガーを開く |
| Ctrl+M | マウスのキャプチャの切り替え |
| ドラッグ&ドロップ | ディスクイメージ・テープ・ハードディスクを挿入 |

macOS では、Cmd+Q でアプリを終了します。

## メニュー

オリジナルの EmuZ-2500 と同じ構成です。

| メニュー | 内容 |
|----------|------|
| Control | リセット、ステートの保存・復元(Save / Load State...)、起動モード、CPU、デバッグ関連など |
| FD1〜FD4 | フロッピーの挿入・取り出し、空のディスクの作成、複数イメージの切り替え、最近使ったファイル |
| CMT | テープの再生・録音・巻き戻し・早送りなど |
| HD1〜HD2 | ハードディスクの接続・取り外し、空のイメージの作成 |
| Device | キーボード、マウス、プリンタなどの設定 |
| Host | サウンド(Rec Sound / Volume など)、画面(縦横比・拡大率・フィルタ)、入力、Wait Vsync、スクリーンショット |

## ステート

Control メニューの「Save / Load State...」で、スロットごとに保存・復元・削除ができます。保存済みのスロットには、日時とサムネイルを表示します。ホットキーでは、スロット1〜4を扱えます。

## 設定ファイル

設定は、終了時にデータフォルダの `mz2500.ini` へ保存され、次の起動で復元されます。保存される項目は、オリジナルの EmuZ-2500 と同じです。本体・画面・サウンド・入力の設定、最近使ったファイルの履歴、音量などが含まれます。保存したくない場合は、`-nosaveconfig` を指定してください。

## デバッガー

Control メニューの「Debug Main CPU」(または Ctrl+D)で開きます。別のウィンドウのコンソールが開きます。開けない環境では、アプリのウィンドウ内に表示します。`?` でコマンドの一覧を表示し、`Q` で終了します。コマンドラインで `-debug` を指定すると、起動時に開きます。

## ノイズ音

FDD のシークやテープのリレー音などの WAV ファイル(`FDDSEEK.WAV` など)は、データフォルダに無ければ自動で生成します。好みの音に差し替える場合は、同じ名前のファイルを置いてください。
